# SE Lab 1 – Requirements Engineering & UML Use-Case Modelling

This repository contains the deliverables for Software Engineering Lab 1, based on the **Student Startup Crowdfunding Platform** problem statement.

## Problem Overview

The system is a crowdfunding platform for university student ventures that supports campaign creation, backer pledges and reward tiers, milestone verification, and tranche-based fund release.

## Contents

- **Requirements Table** – Contains 5 Functional Requirements (FRs) and 2 Non-Functional Requirements (NFRs), along with priorities, acceptance criteria, and rationale.
- **Use-Case Diagram** – Represents the system actors, major use cases, and `<<include>>` / `<<extend>>` relationships.
- **Use-Case Flow** – Describes the preconditions, postconditions, main success scenario, and an alternate flow for the core **Release Fund Tranche** use case.
